# 📱 CuraTrack Mobile – Android Development & Local Setup Guide

> **Version:** 1.0  
> **Platform:** Android Only  
> **Objective:** Build the Android version of CuraTrack V2 by reusing the existing FastAPI backend and Supabase infrastructure, and run it locally on multiple Android devices without deploying the backend.

---

# Overview

CuraTrack Mobile is **not a new backend**.

The existing backend remains unchanged.

Current Architecture

```
Next.js

↓

FastAPI

↓

Supabase
```

becomes

```
React Native Android App

↓

FastAPI (Running on Laptop)

↓

Supabase

↓

PostgreSQL
```

Only the frontend changes.

Everything else is reused.

# Running the Backend Locally

Start FastAPI.

```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

The important option is

```
--host 0.0.0.0
```

This allows Android devices to access the backend.

---

# Find Laptop IP Address

Windows

```bash
ipconfig
```

Find

```
IPv4 Address
```

Example

```
192.168.1.15
```

---

# Configure API URL

Instead of

```
http://localhost:8000
```

use

```
http://192.168.1.15:8000
```

Every API request from the Android application will use this address.

---

# Running the Mobile Application

Start Expo.

```bash
npx expo start
```

or

```bash
npx expo start --dev-client
```

A QR Code will appear.

---

# Installing the App

Install

```
Expo Go
```

or use an

```
Expo Development Build
```

on the Android phones.

Scan the QR Code generated by Expo.

The application will launch.

## Step 1

Connect

- Laptop
- Phone A
- Phone B

to the **same Wi-Fi network**.

---

## Step 2

Run FastAPI.

```
Laptop

↓

FastAPI

↓

192.168.1.15:8000
```

---

## Step 3

Start Expo.

```
Laptop

↓

Expo

↓

QR Code
```

---

## Step 4

Scan the QR Code on both Android phones.

```
Phone A

↓

React Native App

Phone B

↓

React Native App
```

Both applications now connect to the same backend.

# Conclusion

The Android version of CuraTrack is built by replacing only the web frontend with a React Native application while reusing the existing FastAPI backend, Supabase authentication, and PostgreSQL database. During development, the backend runs locally on a laptop, and multiple Android devices connect to it over the same Wi-Fi network using the laptop's local IP address. This approach enables rapid development, easy testing on multiple phones, and seamless integration with future Android-specific capabilities such as BLE, Wi-Fi Direct, offline storage, and disaster communication without requiring backend deployment.
